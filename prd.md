# PRODUCT REQUIREMENTS DOCUMENT (PRD)

Project Name: Seniors 2026
Type: Private Graduation Platform
Target Users: High school seniors (~18 years old)
Access: Private login-only platform

---

## 1. PRODUCT VISION

Seniors 2026 is a private digital space where a graduating class documents memories, celebrates classmates and teachers, and preserves a shared emotional archive before graduation.

The platform should feel modern, nostalgic, social, and meaningful — never childish or cringe.

---

## 2. PRODUCT GOALS

* Create a shared digital memory hub.
* Encourage participation from all students.
* Preserve memories permanently.
* Allow controlled moderation.
* Deliver a memorable graduation experience.

---

## 3. USER ROLES

### Student

* Login to platform
* View all approved content
* Create posts and memories
* Vote in awards
* Write time capsule message
* Send teacher appreciation

### Admin

* Manage users
* Moderate all content
* Control platform features
* Reveal awards results
* Control graduation countdown

---

## 4. AUTHENTICATION

* No public signup.
* Accounts pre-created by admins.
* Login using email + password.
* Optional password change.
* Role-based access control.

---

## 5. CORE FEATURES

### 5.1 Home

* Graduation countdown
* Navigation hub
* Admin-controlled date

### 5.2 Seniors Directory

* Student profiles grid
* Profile info:

  * Photo
  * Nickname
  * Quote
  * Fun fact
* Submit memories about classmates
* No reactions

### 5.3 The Wall

Community board.

Students post:

* Funny moments
* Quotes
* Short posts
* Memes

All posts require admin approval.

### 5.4 Memory Feed

Social timeline.

Students upload:

* Photos
* Videos
* Captions

Admin moderation required.

Uploads can be locked after graduation.

Feed becomes archive afterward.

### 5.5 Seniors Awards

Voting system.

Rules:

* One vote per question per student
* Student search selection
* Results hidden initially
* Admin reveals results later

### 5.6 Hall of Thanks

Teachers appreciation.

Each teacher has:

* Card
* Dedicated page

Students submit anonymous messages.

Admin approval required.

### 5.7 Time Capsule

Private personal messages.

Student writes future goals.

Option:

* Visible to admin
* Private

User can revisit message anytime.

---

## 6. ADMIN DASHBOARD

Sections:

Users Management

* edit user info
* reset password
* activate/deactivate users

Moderation

* student memories
* wall posts
* timeline uploads
* teacher messages

Website Settings

* graduation countdown date
* enable/disable uploads
* enable/disable voting
* reveal awards results

---

## 7. CONTENT MODERATION

All user-generated content contains status:

pending
approved
rejected

Only approved content is publicly visible.

---

## 8. STORAGE

Media storage categories:

* profile images
* memories media
* wall media

---

## 9. NON-FUNCTIONAL REQUIREMENTS

* Fast loading experience
* Mobile responsive
* Secure authentication
* Role-based authorization
* Smooth animations
* Clean modern design

---

## 10. EXPERIENCE PRINCIPLES

The platform must feel:

* Emotional
* Modern
* Authentic
* Social
* Nostalgic

Avoid:

* childish visuals
* school clichés
* cluttered UI

---

## 11. SUCCESS METRICS

* High student participation
* Daily revisits
* Memory submissions growth
* Full engagement before graduation
